# DevOps Lab: Backup Script

Это мой первый учебный проект в рамках подготовки к позиции Junior DevOps.

## Что делает скрипт
Скрипт `backup.sh` автоматизирует процесс резервного копирования логов. 
Он собирает системные логи в архив `.tar.gz` и сохраняет их в папку `backups/`, добавляя к имени файла текущую дату и время.
